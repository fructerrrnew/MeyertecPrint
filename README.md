# MEYERTEC PRINT — исправленная версия

В архиве:

- `Windows_x64/` — собранная версия для Windows x64;
- `Source/` — исходный проект и автоматические проверки;
- `CRITIC_STATUS.md` — состояние всех пунктов исходного `critic.md`;
- `critic.md` — исходный перечень замечаний.

## Запуск в Windows

1. Полностью распакуйте архив в папку, доступную для записи.
2. Установите **.NET Desktop Runtime 10, x64** с официальной страницы Microsoft: https://dotnet.microsoft.com/download/dotnet/10.0 . Нужен именно Desktop Runtime, а не только обычный .NET Runtime.
3. Запустите `Windows_x64/MeyertecPrint.exe`. Папки `Catalog`, `Languages`, `Plugins`, `IconsUI`, `cleat` и все DLL должны оставаться рядом с программой.
4. Для печати установите драйвер и очередь принтера в Windows. USB и Ethernet в программе используют эту очередь; ввод адреса не создаёт порт или драйвер.

**Сборка выполнена для Windows x64, но в этой среде сама программа и реальный принтер не запускались.** Проверьте основные сценарии на своём ПК, прежде чем использовать программу для производственной маркировки.

## Работа с массовыми данными

1. Создайте проект и добавьте на макет текстовые поля, QR- или штрихкоды. Постоянные изображения можно оставить на макете.
2. Выберите **Файл → Импорт CSV**. Поддерживаются `;`, `,`, табуляция, кавычки, многострочные значения и кодировки UTF-8, UTF-16, Windows-1251. Автоматический режим сначала пробует UTF-8, затем Windows-1251; при сомнении явно выберите кодировку и проверьте предпросмотр.
3. При необходимости отметьте наличие заголовков. Для каждого поля укажите столбец или оставьте постоянное значение. Все неиспользованные непустые столбцы потребуют подтверждения. Первая строка данных изменит текущий макет, остальные образуют партию. Новый импорт заменяет предыдущую партию.
4. Вкладка «Лента» показывает текущий макет и печатаемые записи. Записи можно редактировать, дублировать, удалять и менять местами. Первая запись редактируется в редакторе макета и остаётся первой.
5. В предпросмотре переходите между записями. В настройках печати укажите диапазон и количество копий. Импортированные записи включены по умолчанию; этот флажок можно выключить.
6. Проверьте материал, ширину подложки, шаг подачи, расположение и настройки датчика в драйвере. Проверьте первый отпечаток. Автоматическая проверка размеров не подтверждает физическую точность или считываемость кодов.

CSV сопоставляется с полями при импорте; названия заголовков не являются постоянными идентификаторами объектов макета. Если после импорта изменился состав или порядок объектов, заново проверьте сопоставление и партию. Прямой импорт XLSX пока не реализован: сохраните лист как CSV и проверьте сохранность ведущих нулей.

В редакторе выбранный свободный объект можно копировать через Ctrl+C и вставить через Ctrl+V, когда фокус находится на холсте. Это внутреннее копирование приложения. Доступны также отмена и повтор действий редактора.

## Автосохранение

Изменённый проект периодически записывается в `%LOCALAPPDATA%\MeyertecPrint\Recovery` примерно раз в минуту. После аварийного завершения при запуске предлагается восстановить последнюю доступную копию как несохранённый проект; сохраните её под выбранным именем. Текущий незавершённый ввод внутри поля может ещё не попасть в копию. При нормальном закрытии с отказом от сохранения копия текущей сессии удаляется. Автосохранение не заменяет обычное сохранение и внешние резервные копии.

Журнал непредвиденных ошибок: `%LOCALAPPDATA%\MeyertecPrint\errors.log`. Он может содержать пути к локальным файлам и диагностические сведения, поэтому просмотрите его перед передачей в поддержку.

## Исходники и проверки

Для сборки нужен .NET SDK 10. В PowerShell из папки `Source`:

```powershell
dotnet restore
dotnet build -c Release
dotnet run --project tests/CoreTests/CoreTests.csproj
dotnet run -- --selftest
```

`CoreTests` проверяет независимую от интерфейса логику; `--selftest` дополнительно затрагивает Windows Forms и рисование и должен выполняться в Windows. В этой среде проверено: компиляция Windows x64 и 24 проверки CoreTests. Тесты не заменяют проверку окон Windows, драйвера и печати на оборудовании.

## WSTX

Совместимость с файлами сторонних программ WAGO не подтверждена. Несколько блоков и некоторые неизвестные типы содержимого отклоняются, чтобы не терять их молча; это не означает, что все варианты WSTX поддерживаются. В качестве основного формата сохранения используйте `.mprj` и храните резервную копию исходного WSTX.

# Установщики MEYERTEC Print

Оба пакета содержат приложение и соответствующую среду .NET для x64. Исходные проекты и сохранённые пользовательские данные хранятся отдельно от установленных файлов приложения.

На Linux для сборки нужны Python 3 и .NET SDK 10. Для Windows MSI требуется `wixl` из пакета `wixl` на Debian. Для пакета Linux требуется `dpkg-deb`. Выполните команды из корня репозитория.

```bash
python3 packaging/build.py windows --output /tmp/meyertec-installers
python3 packaging/build.py linux --output /tmp/meyertec-installers
```

Параметр `--from-publish /путь/к/публикации` упаковывает готовую обычную самодостаточную сборку той же платформы. По умолчанию версия пакета берётся из `MeyertecPrint.csproj`. Для отдельной сборки можно передать `--version`.

## Windows x64

Откройте файл `.msi` на Windows. Для установки в Program Files потребуются права администратора. Приложение появится в меню «Пуск». Удалить его можно через раздел «Установленные приложения». MSI использует цифровую трёхчастную версию приложения. MSI этой сборки не подписан сертификатом издателя.

## Linux amd64

Пакет `.deb` рассчитан на Debian 12/13 и совместимые системы с графической сессией. Для установки файла вместе с системными зависимостями запустите следующую команду.

```bash
sudo apt install /tmp/meyertec-installers/meyertecprint_0.4.0~preview_amd64.deb
```

Запустить программу можно из меню приложений или командой `meyertecprint`. Для удаления используйте `sudo apt remove meyertecprint`.
